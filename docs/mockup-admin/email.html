Come leggere lo stato Proposta, prompt 24 e 25

"Inviata" significa accettata dal server di posta: non vuol dire che sia stata consegnata o letta. Se la casella del destinatario è piena o l'indirizzo è sbagliato, l'email può tornare indietro più tardi.

Errore tradotto in istruzione: "Il server di posta ha rifiutato la password: controllala in Sistema › Email."

Configurazione del server di posta Proposta, prompt 26 D1: da approvare
