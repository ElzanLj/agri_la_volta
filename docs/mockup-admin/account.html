Account Nuovo, prompt 17

Ultimo accesso riuscito: 7 ott 2026, 09:12. Tentativi di accesso falliti nelle ultime 24 ore: 2. segnalazioni, prompt 17 D6

Cambia la password

Almeno 12 caratteri. Non può essere una password comune (es. "Agriturismo2026!") né contenere il nome utente. D4

Dopo il cambio, gli altri dispositivi collegati vengono disconnessi.

Esci da tutti i dispositivi Proposta, prompt 17 D5: da approvare

Se hai perso il telefono o hai mostrato la password a qualcuno: chiudi tutte le altre sessioni senza cambiare la password. Ti viene chiesta la password attuale.

Conferma della password (riautenticazione) Prompt 17: usata dai prompt 24, 26 e 27

Esempio: le azioni sensibili (salvare la configurazione email, applicare un aggiornamento, scaricare un backup, anonimizzare dati) ti chiedono di nuovo la password. La conferma vale 5 minuti.

Password dimenticata?

Non esiste un recupero via email. La procedura senza SSH (generare il comando sul computer dello sviluppatore e importarlo in phpMyAdmin) è descritta nel manuale.
