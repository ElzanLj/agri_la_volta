Backup Proposta, prompt 27 D4–D5: da approvare

Il backup viene creato al momento e scaricato sul tuo computer; non resta sul server. Conservalo su un disco o un cloud personale.

Il ripristino si fa con phpMyAdmin: la procedura è nel manuale.

Cosa non si cambia da qui

Credenziali del database, chiave di sicurezza (APP_SECRET), indirizzo del sito e modalità debug si impostano una volta sull'hosting: se si potessero cambiare dal browser, chi rubasse l'accesso admin prenderebbe il controllo del server.
