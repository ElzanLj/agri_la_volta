# Prompt 90 — Inizio sessione

Prima di modificare codice:

1. leggi `AGENTS.md`;
2. leggi `docs/SESSION_STATE.md`;
3. leggi `docs/PLAN.md`, `docs/TODO.md`, `docs/MISSING_DATA.md`, `docs/DECISIONS.md`;
4. leggi il prompt della fase corrente;
5. esegui `git status` e ispeziona i diff locali pertinenti;
6. consulta `docs/COMMANDS.md` e `docs/TEST_REPORT.md`;
7. riassumi in massimo 10 righe lo stato reale;
8. scegli un solo obiettivo principale completabile nella sessione;
9. indica file previsti e verifiche da eseguire.

Non sovrascrivere modifiche locali non comprese. Poi procedi con l'obiettivo.
