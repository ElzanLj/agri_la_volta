# Prompt 12 — Documentazione tecnica e consegna

## Obiettivo

Rendere il progetto installabile e manutenibile da un'altra persona senza ricostruire mentalmente l'architettura.

## Documenta almeno

1. riepilogo modifiche;
2. architettura finale;
3. struttura progetto;
4. schema DB;
5. migrazioni;
6. configurazioni;
7. `.env.example`;
8. sviluppo locale;
9. installazione hosting condiviso;
10. import DB;
11. SMTP;
12. creazione/modifica admin;
13. backup;
14. ripristino;
15. export CSV;
16. test eseguiti;
17. risultati;
18. limitazioni;
19. informazioni mancanti;
20. checklist pubblicazione.

## Regole

- documenta il repository reale, non un'architettura ideale;
- verifica i comandi quando possibile;
- niente segreti;
- niente deploy;
- evidenzia passaggi che richiedono provider/autorizzazione esterna.

Aggiorna README applicativo e documenti sotto `docs/` secondo necessità. Mantieni separato questo prompt pack dalla documentazione utente se il progetto richiede una struttura diversa.
